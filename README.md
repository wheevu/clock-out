# 퇴근

A 3D deckbuilding office RPG about getting out of work.

You wake at 3:17 AM inside 성광정보기술.
The commute is a dungeon, your manager is a boss fight, and the exits are resignation or promotion.

The current build has a hand-written 640 by 360 software renderer, deterministic combat, physics weapons, Hangul composition, dialogue, scheduling, relationships, and ten scripted presentation screens.

It is still a vertical slice.
The screens render real engine state, but the playable application loop and input flow are not wired yet.
